= Zukunftshaus Karlsruhe - Website

Website der Baugruppe Zukunftshaus Karlsruhe für gemeinschaftliches, bezahlbares und nachhaltiges Wohnen im Quartier Zukunft Nord.

Erreichbar unter: https://christlang.github.io/zukunftshaus-website/

== Projektstruktur

[source]
----
├── index.html          # Hauptseite
├── impressum.html      # Impressum
├── scripts/
│   ├── setup-fonts.sh        # Script: Fonts herunterladen
│   ├── create-favicon.sh    # Script: Favicon aus Logo erstellen
│   └── create-logo-small.sh # Script: mobil-optimierte Logo-Variante erstellen
├── css/
│   └── style.css       # Stylesheet
├── fonts/              # Lokale Fonts (Inter, Font Awesome)
└── images/
    ├── logo.png        # Logo (Original, 1024x1024)
    └── logo-small.png  # Logo, klein/komprimiert (Header/Footer, mobile)
----

== Fonts aktualisieren

Die Fonts (Inter, Font Awesome) sind im Repository enthalten. Bei Bedarf können sie mit folgendem Script aktualisiert werden:

[source,bash]
----
./scripts/setup-fonts.sh
----

== Favicon aktualisieren

Das Favicon wird aus dem Logo generiert. Benötigt ImageMagick.

[source,bash]
----
./scripts/create-favicon.sh
----

== Mobil-optimiertes Logo aktualisieren

Header und Footer zeigen das Logo nur mit 50-60px Höhe an, das Original
(`site/images/logo.png`) ist jedoch 1024x1024px groß (~1,4 MB). Für diese
Anzeigegröße wird stattdessen `site/images/logo-small.png` ausgeliefert
(200x200px, komprimiert via `pngquant`, ~16 KB) - über `srcset` eingebunden,
sodass auch bei Retina-Displays noch genug Auflösung vorhanden ist. Bei
Bedarf (z. B. nach Logo-Änderung) neu erzeugen mit:

[source,bash]
----
./scripts/create-logo-small.sh
----

Benötigt ImageMagick und `pngquant`.

== Lokale Entwicklung

Die Website besteht aus statischen HTML-Dateien ohne Build-Prozess.

=== Option 1: Direkt im Browser

Die Datei `site/index.html` kann direkt im Browser geöffnet werden.

=== Option 2: Lokaler Server

[source,bash]
----
cd site
npx serve
----

Anschließend im Browser http://localhost:3000 aufrufen.

== Seitenstruktur

Die Hauptseite (`index.html`) enthält folgende Abschnitte:

* *Hero* - Willkommensbereich mit Claim
* *Status* - Timeline mit Projektphasen
* *Über uns* - Vorstellung der Baugruppe und Werte
* *Das Projekt* - Standort, Wohnformen, Gemeinschaftsräume, Nachhaltigkeit
* *Mitmachen* - Optionen zur Beteiligung
* *Kontakt* - E-Mail-Kontakt

== Styling

Das Stylesheet (`css/style.css`) verwendet CSS Custom Properties für:

* Farbpalette (abgeleitet vom Logo)
* Abstände
* Typografie

Responsive Breakpoints:

* Mobile: < 768px
* Tablet: 768px - 1023px
* Desktop: >= 1024px

== Visueller Vergleich mit BackstopJS

Unter `tests/backstop/` liegt ein BackstopJS-Setup, das die Produktivseite
(`https://www.zukunftshaus-ka.de/`) per Screenshot-Vergleich gegen eine
andere Domain (z. B. eine Test-/Staging-Instanz wie `https://zukunftshaus.cutl.de/`)
prüft - für Startseite und Impressum, jeweils in den Viewports mobile
(375px), tablet (768px) und desktop (1440px).

Die zu vergleichenden URLs sind pro Szenario in `tests/backstop/backstop.json`
über `referenceUrl` (Referenz) und `url` (zu testende Seite) hinterlegt.

[source,bash]
----
cd tests/backstop
npm install
npx backstop reference   # Referenz-Screenshots von referenceUrl erzeugen
npx backstop test        # Vergleich gegen url, Diff-Report öffnen
----

link:tests/backstop/backstop_data/html_report/index.html[Backstopjs-Report]

Der HTML-Report (inkl. Slider-Ansicht je Szenario) liegt anschließend unter
`tests/backstop/backstop_data/html_report/index.html` und wird nicht
versioniert.
